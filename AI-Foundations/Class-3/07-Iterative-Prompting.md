# 2. Iterative Prompting 🔄

## What is Iterative Prompting?

Iterative Prompting means:

> **Improve your prompt step by step until you get the perfect answer.**

Most professionals do **not** get the perfect result on the first try.

They improve the prompt little by little.

---

### Example

### First Prompt

```text
Write a blog.
```

The answer is okay.

---

### Second Prompt

```text
Write a 500-word blog.
```

Better.

---

### Third Prompt

```text
Write a 500-word blog.

Use simple English.

Add headings.

Add examples.

Use bullet points.
```

Much better.

---

### Fourth Prompt

```text
Write a 500-word blog.

Target audience:
Beginners

Tone:
Friendly

Use real-life examples.

Add a summary.
```

Now the answer is excellent.

---

### Think of Cooking 🍕

Imagine making pizza.

First attempt:

Needs more cheese.

Second attempt:

Needs more sauce.

Third attempt:

Perfect!

Prompting works the same way.

---

### Easy Rule

> **Iterative Prompting = Keep improving your prompt until the result is exactly what you want.**
