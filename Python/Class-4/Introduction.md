# Python Introduction (Complete Beginner Guide)

## What is Python?

**Python is a programming language.**

A programming language is a way to **talk to a computer**.

Just like humans use English or Urdu to communicate, programmers use programming languages to give instructions to computers.

Example:

Instead of saying to a person:

> "Print Hello"

We write in Python:

```python
print("Hello")
```

The computer understands this instruction and shows:

```
Hello
```

---

# What is Programming?

Programming means:

> **Writing instructions for a computer to perform tasks.**

These instructions are called **code**.

Example:

You tell your friend:

1. Open the door
2. Turn on the light
3. Bring water

These are instructions.

Similarly, we write instructions for computers.

---

# What is a Program?

A **program** is a collection of instructions written in a programming language.

Example:

```python
print("Ali")
print("Welcome")
print("Have a nice day")
```

This small program prints three lines.

# What is Python Syntax?

Syntax means:

> **The rules for writing Python code.**

Just like English has grammar, Python has syntax.

Correct:

```python
print("Hello")
```

Incorrect:

```python
print Hello
```

Python follows specific rules.

# How Does Python Work?

Simple process:

```
You write code
        ↓
Python reads it
        ↓
Python executes it
        ↓
You get the result
```

Example:

```python

```

Output:

```
8
```
