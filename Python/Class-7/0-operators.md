# What is an Operator?

An **operator** is a **symbol** that tells Python to perform an operation.

Simple definition:

> **An operator is a symbol used to perform a task on values or variables.**

Examples:

```text
+
-
*
/
=
==
>
<
```

Each operator has a different job.

---

# Real-Life Example

Think about a calculator.

It has buttons like:

```text
+
-
×
÷
```

When you press `+`, the calculator adds numbers.

Python operators work the same way.

---

# Types of Operators

Python has many operators, but beginners should first learn these **four categories**.

| Type                 | Purpose                       |
| -------------------- | ----------------------------- |
| Arithmetic Operators | Perform calculations          |
| Comparison Operators | Compare values                |
| Assignment Operators | Store or update values        |
| Logical Operators    | Combine True/False conditions |

We'll learn them one by one.
