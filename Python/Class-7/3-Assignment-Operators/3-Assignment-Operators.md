# Part 3: Assignment Operators

Assignment operators are used to **store or update values**.

---

## Basic Assignment (`=`)

```python
age = 20
```

This stores 20 in `age`.

---

## Add and Assign (`+=`)

```python
age = 20

age += 5

print(age)
```

Output

```text
25
```

This is the same as:

```python
age = age + 5
```

---

## Subtract and Assign (`-=`)

```python
age = 20

age -= 3

print(age)
```

Output

```text
17
```

---

## Multiply and Assign (`*=`)

```python
salary = 100

salary *= 2

print(salary)
```

Output

```text
200
```

---

## Divide and Assign (`/=`)

```python
number = 20

number /= 2

print(number)
```

Output

```text
10.0
```

---

# Assignment Operator Summary

| Operator | Example  | Meaning            |
| -------- | -------- | ------------------ |
| `=`      | `x = 5`  | Store value        |
| `+=`     | `x += 2` | Add and store      |
| `-=`     | `x -= 2` | Subtract and store |
| `*=`     | `x *= 2` | Multiply and store |
| `/=`     | `x /= 2` | Divide and store   |
