# Part 2: Comparison Operators

Comparison operators compare two values.

The answer is always:

```text
True
```

or

```text
False
```

---

## Equal To (`==`)

```python
print(5 == 5)
```

Output

```text
True
```

---

```python
print(5 == 8)
```

Output

```text
False
```

---

## Not Equal (`!=`)

```python
print(5 != 3)
```

Output

```text
True
```

---

```python
print(5 != 5)
```

Output

```text
False
```

---

## Greater Than (`>`)

```python
print(10 > 5)
```

Output

```text
True
```

---

## Less Than (`<`)

```python
print(3 < 7)
```

Output

```text
True
```

---

## Greater Than or Equal (`>=`)

```python
print(10 >= 10)
```

Output

```text
True
```

---

## Less Than or Equal (`<=`)

```python
print(8 <= 5)
```

Output

```text
False
```

---

# Comparison Operator Summary

| Expression | Output  |
| ---------- | ------- |
| `5 == 5`   | `True`  |
| `5 != 5`   | `False` |
| `7 > 3`    | `True`  |
| `2 < 1`    | `False` |
| `5 >= 5`   | `True`  |
| `4 <= 2`   | `False` |
