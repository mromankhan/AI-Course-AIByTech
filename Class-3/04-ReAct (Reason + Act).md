# 2. ReAct (Reason + Act)

## What is ReAct?

ReAct means:

> **The AI thinks, performs an action, checks the result, and then continues.**

Instead of only thinking...

It can also use tools.

---

### Example

You ask:

```text
What is today's weather in Karachi?
```

The AI may:

**Thought**

"I need live weather."

↓

**Action**

Search the internet.

↓

**Observation**

Weather is 34°C.

↓

**Final Answer**

"It is currently 34°C in Karachi."

---

Another Example

You ask:

```text
Find the cheapest flight from Karachi to Dubai.
```

The AI:

* thinks
* searches airline websites
* compares prices
* gives the best option

---

### Think of Google

Imagine you're solving homework.

You don't know the answer.

So you:

Think

↓

Search Google

↓

Read results

↓

Answer

That's ReAct.

---

### Easy Rule

> **ReAct = Think → Take Action → Observe → Answer.**
