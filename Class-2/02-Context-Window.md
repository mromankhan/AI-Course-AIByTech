# 2. Context Window 🧠

## What is a Context Window?

A Context Window is the AI's **short-term memory**.

It remembers only a limited amount of information while chatting.

---

### Simple Example

Imagine a classroom.

The teacher writes on a whiteboard.

But the board has limited space.

When the board becomes full...

The teacher erases the oldest writing.

Then writes new information.

That's exactly how a Context Window works.

---

### Example

Suppose the AI can remember only:

* Page 1
* Page 2
* Page 3

Now you add:

* Page 4
* Page 5

The AI may start forgetting Page 1 because the memory is full.

---

### Why is it Important?

If your conversation becomes very long...

The AI may forget:

* your first instructions
* your first question
* earlier details

because they no longer fit inside the context window.

---

### Easy Rule

> **Context Window = The AI's temporary memory during a conversation.**
